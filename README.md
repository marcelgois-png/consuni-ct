# Consuni · Direção do CT/UFPB

Resultado das pautas do Conselho Universitário (Consuni) da UFPB acompanhadas pela Direção do Centro de Tecnologia: situação de cada item e tramitação dos processos no SIPAC público.

Uma pasta por reunião (`AAAA-MM-DD-<tipo>-NN/index.html`). Esta versão pública não traz as análises da Direção nem os PDFs dos processos; nos itens de interesse individual, os nomes são omitidos. Vale sempre a informação dos sistemas oficiais da UFPB.
